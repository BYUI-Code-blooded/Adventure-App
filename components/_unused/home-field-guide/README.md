# DO NOT USE

`HomeFieldGuide.tsx` is a basic mockup of an alternative home page design ("Field Guide"). It was used briefly and then replaced. Nothing imports it, and the live home page is `app/page.tsx`.

What the design looked like, in case the team revisits it:
- Warm off-white page (`stone-50`) with dark `stone-900` text and a single orange accent (`orange-700` text, `orange-600` lines).
- Serif headlines, square corners, no shadows or gradients.
- The nav was a `stone-50` header with a `border-b border-stone-300`, a serif italic site name, and an `orange-600` underline on the active link.

It is not part of the current style guide (`docs/style-guide.md`). It still compiles, so `npm run build` and `npm run lint` check it. If it breaks, fix it or delete this folder.
