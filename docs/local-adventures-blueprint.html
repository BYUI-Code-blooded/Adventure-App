    03 · Vocabulary

    Next.js is React with routes, build and deploy included.

    Try it · click a layer or a tool

    Nine words, nine pictures

    Language

    Words we write code in. We use TypeScript: JavaScript with types, so wrong data is flagged before it runs.

    Library

    Code you call when you need it. Leaflet draws the map, supabase-js talks to the database.

    Framework

    A structure that organizes the project and calls your code. Next.js decides where pages live.

    Component

    A reusable piece of a page, like EventCard.

    Route

    The web address of a page. The folder app/outdoor/ becomes /outdoor.

    Build

    Turns our code into the final files. Run npm run build.

    Deploy

    Puts the built files on the internet. Every merge to main deploys on Vercel.

    Database

    Shared storage that every user reads and writes. Supabase runs PostgreSQL.

    RLS

    Row Level Security: rules in the database for who can read or change each row.

    04 · Choosing the stack

    Next.js looks like the best fit for our team and our map.

    Easy for beginnersMediumMediumHighMedium
    Tidy with 4 peopleHighHighLowMedium
    AI tool resultsHighHighMediumMedium
    Chance of getting stuckLowLowMediumHigh
    Why not Python?

    A great language, a poor fit for this project

    • 1The map runs in the browser, and browsers run JavaScript.
    • 2Flask, Django and Streamlit need a running server, which we want to avoid.
    • 3Pyodide (Python in the browser) is still experimental.

    Python teammates still own filters, tests and sample data.

    09 · The repository

    The repo is the source of truth for people and AI alike.

    Try it · click the tree

    How the rule files connect

    Rules written as "do not"

    No API routes. Static export (output: 'export') cannot run them.

    No new packages without asking. Only the tech lead edits package.json.

    No invented columns. docs/data-model.md is the truth.

    No Leaflet on the server. Load it with dynamic(..., { ssr: false }).

    No edits to supabase/schema.sql unless the lead asks.

    No merge without a passing npm run build.

    Known pitfalls and their fixes

    What goes wrongFix
    The map page crashes the buildLoad Leaflet client-only: dynamic(() => import(...), { ssr: false })
    Marker icons show as broken imagesSet the icon URLs with L.Icon.Default.mergeOptions(...) (kept in docs/gotchas.md)
    An evening event shows on the wrong dayStore timestamptz and group days in America/Denver
    Anonymous visitors can write when we did not expect itAnonymous users get the authenticated role. Test the RLS policies early
    Supabase stops answering after a quiet weekFree projects pause after about a week. Resume with one click
    Email codes never arriveTest SMTP delivery in sprint 0, or stay anonymous
    The build fails on an API routeoutput: 'export' has no server. Call Supabase from the browser with supabase-js
